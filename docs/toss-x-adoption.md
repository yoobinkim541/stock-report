# 대시보드 통합·배포

## 통합 계약

- 뉴스 제목의 종목 추출은 `ticker_names.mentions_in` 하나만 사용한다. 별도 파서·정규식 폴백은 두지 않는다. 뉴스의 구조화된 티커 필드는 우선한다.
- 사용처가 없던 `result_catalog`와 `pairs.result_ids`는 제거했다. 전략 ID·가중치·실주문은 이 릴리스에서 변경하지 않는다.
- 비교 일봉 조회는 6개월 이하 `5y`, 1년 이하 `10y`, 그 이상/전체 `max`. `charts.view_window`의 5배 팬 버퍼와 250봉 워밍업을 보존한다. 주·분봉 조회는 유지한다.
- 리플레이 상단 가격은 종목 정규화 후 통화·매크로 단위를 표시한다. 지수에 달러를 붙이지 않는다.
- Plotly 줌·팬 종료 시 고점·저점 주석의 좌표·문구가 바뀐 필드만 갱신한다. 제스처 중 y축 갱신 억제는 유지한다.

## 운영 병합

공통 버전 `7be5f2d6ded0ab5f9222ef8355d57d060aa2a588`과 운영 스냅샷으로 3-way 병합했다. 전체 저장소를 덮어쓰지 않고 명시한 파일만 반영했다. 운영의 차트 봉 마감·신선도 정책, 관심종목 시세 기준·출처, 위키 검색·건강 지표·출처 검증을 보존했다. 관심종목 편집기가 호출하던 누락된 저장 함수를 공용 `lib.watchlist`에 연결하고, 삭제는 확인 버튼에서만 실행하도록 검증했다.

## 실측·발견

- 로컬 첫 진입에서 `dashboard/data.py:15` 들여쓰기 오류 확인. UI 담당이 수정하고 해당 6개 테스트 통과를 보고했다.
- 홈·종목 헤더의 HTML 조각이 코드 블록으로 노출되던 문제와 밝은 테마의 흰색 선택상자 글씨를 수정하고 실제 화면에서 확인했다.
- 로컬 MSFT 최초 차트: 문서 시작 후 iframe 생성 7,277ms, iframe 첫 콘텐츠 페인트 1,144ms. 외부 데이터·CDN을 포함한 단일 관측이며 p95가 아니다.
- 실제 Plotly 소폭 휠 줌에서 값이 모두 같은 고점·저점 주석 재갱신에 193.5ms가 걸렸다. 변경 필드만 갱신하도록 수정했다. 병합 후보의 실제 GOOGL 렌더러에서 범위 변경 API를 실행했을 때 범위 갱신은 201.3ms, 호버 복원은 16.4ms였으며 동일한 주석 갱신은 없었다. 종목과 제스처 입력 방식이 달라 직접적인 전후 속도비로 해석하지 않는다. Orca의 물리 휠 입력이 전달되지 않아 후자는 브라우저 안의 Plotly API로 측정했다.
- 합성 일봉 10,661개 기준: 전체 직렬화 HTML 3,520,619B / 생성 233.94ms, 기존 1년 윈도잉 1,560개는 616,085B / 47.76ms. 기존 윈도잉의 비용 비교이며 이번 수정의 전후 성능 수치가 아니다.
- 브라우저에서 지정가 선택 시 주문가 활성화, 손절·목표 토글 시 두 가격 활성화 확인. 로컬 리플레이 1주 지정가 제출 후 대기 주문 표시·취소 동작 확인. 실계좌 주문 없음.
- 모바일 390px 주문 폼은 화면 폭 안에 표시된다. 별도 캡처로 확인했다.

- 로컬 파서·비교 이력·가격 단위·리플레이·Plotly 회귀 테스트: 88개 통과.
