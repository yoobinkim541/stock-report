# 퀀트 터미널 UI/UX 스토리

대상은 한국 개인 투자자다. 화면 문구는 한국어가 기본이고, 종목 코드·지표 약어(RSI, PER, QQQ)는 그대로 둔다. 랜딩의 영문 아이브로우는 디자인 카피라 번역하지 않는다.

## 홈

- 나는 장 시작 전에 국면과 보유 비중을 한 화면에서 보고 싶다. 그래서 홈은 국면, 보유 요약, 시장 지도를 먼저 보여 준다.
- 시세가 없거나 오래되면 숫자 대신 상태를 말한다. `스냅샷`은 지연, `실시간`은 장중 시세, `오래됨`은 만료다.
- 보유 종목이나 지도를 누르면 종목 분석으로 간다. 한국 6자리 코드도 차트 코드(`005930.KS`)로 맞춰진다.

## 포트폴리오

- 나는 현금·평가·비중을 통화별로 구분해서 보고 싶다. 한국 종목은 원, 미국 종목은 달러로 표시한다.
- 보유가 없으면 "보유 데이터가 없습니다"라고 말하고, 파일 이름이나 스택 추적은 보여 주지 않는다.
- 리스크 문장은 행동이다. "분산이 낮습니다"처럼 다음에 무엇을 보면 되는지 말한다.

## 종목 분석

- 나는 차트를 보고, 가격 알림을 걸고, 관련 종목으로 넘어가고 싶다. 종목 전환은 항상 같은 정규화를 탄다.
- 한국 ETF 체결의 통화는 코드에 `KRW`를 붙이지 않는다. 원이면 `₩`, 달러면 `$`다.
- 데이터 출처는 사용자가 아는 이름이다. `yfinance` 대신 `시세`, `SEC EDGAR` 대신 `미국 공시`, `DART` 대신 `전자공시`.
- 주문을 낼 수 없어도 화면은 이유를 말한다. 수량·가격·장 상태를 확인하라는 문구가 예외 문자열을 대신한다.

## 관심종목 · 리서치 · 차트

- 관심종목에서 종목을 누르면 분석 화면으로 간다. 빈 목록은 추가 방법을 안내한다.
- 리서치 스크리너와 차트 풀뷰의 종목 클릭도 같은 경로를 쓴다. 사이드바 직접 대입은 정규화를 건너뛰므로 쓰지 않는다.
- 차트 워크스페이스에서 저장·불러오기가 실패하면 "다시 시도하세요"라고만 말한다. 경로와 예외 본문은 로그에 남긴다.
- 리플레이 주문 오류는 한국어다. `invalid order` 같은 엔진 문구는 화면에 나오지 않는다.

## 전략 스튜디오 · AI 콘솔

- 나는 전략을 저장하고, 검증이 막히면 이유를 한국어로 보고 싶다. `full_validation_failed` 같은 코드는 화면 문구가 아니다.
- JSON을 직접 고칠 때 파싱이 실패하면 형식 확인을 안내한다. 파이썬 예외는 보여 주지 않는다.
- AI 콘솔의 위키·참조 라벨은 저장된 영문 코드를 한국어로 바꿔 보여 준다. 저장값 자체는 바꾸지 않는다.

## 확인한 수정

| 화면 | 문제 | 수정 |
|---|---|---|
| 홈·관심·포트폴리오·리서치·차트 | 한국 코드 클릭이 정규화를 건너뜀 | `open_ticker`로 통일 |
| 종목 체결·매크로 | 한국 금액을 `$`로 표시 | `trade_money` |
| 종목·포트폴리오·리서치 | `yfinance`, `snapshot`, `SEC EDGAR`가 그대로 보임 | 한국어 라벨 |
| 차트 워크스페이스·리플레이·전략 스튜디오 | 예외 문자열이 오류 창에 출력 | 한국어 안내로 대체 |

## 의도적으로 남긴 것

- 랜딩 페이지의 영문 아이브로우와 브랜드 카피.
- 차트 데이터 탭의 원본 JSON. 개발자 확인용이며, 위에 한국어 상태 문구를 둔다.
- RSI, PER, NAV, QQQ처럼 화면에서 그대로 쓰는 시장 용어.
- 환경변수 이름. 운영자가 설정 파일을 그대로 찾아야 한다.
- 텔레그램 채널 키 `saveticker`. 알림 라우팅 계약이다. 화면에는 "시세 알림"으로 풀어 쓴다.

## 이번 감사에서 더 고친 것

- 차트 워크스페이스 캡션이 `candlestick`, `off`, `PLOTLY`를 그대로 보여 주던 문제. 차트 종류·드로잉·렌더러 상태를 한국어로 바꾼다.
- 렌코·카기 경고와 리플레이 주문 표가 영어 엔진 문구를 그대로 보여 주던 문제. 화면에는 한국어만 남긴다.
- 리플레이와 모의투자 순자산이 영어 `NAV`로 보이던 문제. 라벨을 순자산으로 바꾸고, 리플레이 금액은 종목 통화를 따른다.
- 모의투자 빈 화면이 크론 이름과 환경변수 키를 안내하던 문제. "기록이 아직 없습니다"로 바꾼다.
- 종목 비교에 목록 밖 티커를 치면 입력이 지워지던 문제. 정규화에 성공하면 비교에 넣는다.
- 국내 ETF 순자산이 `B`/`M`으로, 구성 출처가 `KIS`로 보이던 문제. 원 단위와 "시세 구성"으로 바꾼다.

## 이어서 확인한 것

- 나는 국내 종목을 열면 보유 주수와 평단을 보고 싶다. 해외 장부에만 있으면 "미보유"로 보이던 문제를 고쳤다. 평단은 원이다.
- 전략 스튜디오와 AI 콘솔에서 응답이 실패하면 예외 문장 대신 "다시 시도하세요"라고 말한다.
- 시장 화면의 수집 공백은 시간만 말한다. 파이썬 오류 문자열은 붙이지 않는다.
- 가격 알림은 한국 종목이면 원 단위 정수로 보여주고, 미국 종목이면 달러 소수로 보여 준다.
- 리스크·랭킹·백테스트·기관 목록이 실패하면 예외 문장 대신 다시 시도하라는 안내를 보여 준다.
- 종목 화면에서 재무·기관·내부자·공시·실적이 없으면 예외 문장 대신 없는 이유만 짧게 말한다.

## 화면별 시나리오

- 시장: 일정이 비어 있으면 "경제 일정이 비어 있습니다"만 본다. 수집이 멈춘 출처는 이름과 공백만 보이고, 예외 문장은 붙지 않는다.
- 위키: 저장된 페이지가 없으면 빈 상태를 본다. 승격이 막히면 한국어 사유를 보고, 적용이 실패하면 "대상이 이미 바뀌었을 수 있습니다"를 본다.
- 모의투자: 기록이 없으면 "모의 계좌 기록이 아직 없습니다"를 본다. 국내 단기 체결은 원으로, 미국 계좌는 달러로 본다. 행을 누르면 종목 분석으로 간다.
- 차트 풀뷰: 한국 종목 현재가는 원 정수, 미국 종목은 달러 소수다. 시세가 없으면 코드를 확인하라는 안내만 본다.
- 랜딩: 영문 아이브로우는 그대로 둔다. 본문 링크는 터미널과 리서치로 이어진다.

## 위키에서 이어서 고친 것

- 분할 문서의 읽기를 눌러도 선택 상자에 남은 이전 페이지가 이겼다. 읽기와 새 저장은 선택 상자를 그 문서로 맞춘 뒤에 연다. 문서가 없으면 "문서를 열지 못했습니다"를 본다.
- 삭제가 실패하면 화면이 그대로였다. 이제는 "삭제하지 못했습니다"를 본다.
- 위키 관계 그래프가 없는 분류 함수를 호출해 브라우저가 죽었다. 테마 분류를 넣고, 본문 캐시 키도 그래프 모듈의 지문을 쓰게 했다.

## 전략 스튜디오에서 이어서 고친 것

- 데이터 프로필·검증 모드·신호 공급자 선택 상자가 `single_pass`, `legacy_fixed` 같은 내부 키를 보여 줬다. 화면은 한국어이고, 저장되는 값은 그대로다.
- 승격이 막히면 `net_excess` 대신 "비용 차감 초과수익이 없습니다"를 본다. 시세 출처 `yahoo`는 "시세"로 보인다.

## 이어서 맞춘 화면 문구

- 종목 화면에서 공시 출처는 전자공시·미국 공시다. 신뢰도는 높음·보통·일부·없음이고, 실적 마커는 상회·하회다. 진입 존 가격은 한국 종목이면 원, 미국 종목이면 달러다.
- 리서치 축 게이트는 관찰·통과·차단으로 보이고, 권고 축은 52주고점처럼 말한다. 참·거짓은 예·아니오다.
- 모의투자 판단 근거의 `value`·`mom12`·`stale`은 밸류·12개월·오래됨으로 보인다. 원장에 저장된 코드는 바꾸지 않는다.
- 시장 탭의 출처 키는 예측시장·경제 일정처럼 보인다. 포트폴리오 베타 문장은 실제 보유 종목 수를 말한다.

## 위키 미리보기와 차트 시각 분석

- 위키 읽기 캡션과 그래프 툴팁은 화면·종류·상태·확인을 한국어로 보여 준다. 저장 키는 바꾸지 않는다.
- 리서치 미국 축의 멤버십 커버리지가 90% 미만이면 통과가 관찰로 내려간다고 말한다.
- 차트 시각 분석이 실패하면 엔진 코드 대신 다시 시도하라는 안내를 본다. 패턴 종류는 삼각수렴처럼 보인다.

## 전략 레일과 리플레이 규칙

- 전략 상태와 현재 레일은 초안·검증용·모의·실거래로 보인다. 저장되는 환경 키는 바꾸지 않는다.
- 순자산 시계열이 없으면 "표시할 순자산 시계열이 없습니다"를 본다.
- 리플레이에 연결된 규칙은 전략 또는 차트 조건으로 보인다.

- 모의투자 순자산 곡선과 사이드바 도움말은 순자산이라고 말한다. ETF 기준가 약어 NAV는 그대로 둔다.
- 위키 원문 단서와 AI 콘솔 출처는 대화·수집 출처처럼 보인다. URL은 그대로 두고 저장 키는 보여 주지 않는다.
- 위키 병합 기록은 제목과 병합·분할로 보인다. 페이지 id와 `merge`는 보여 주지 않는다.
- AI 콘솔 상태줄은 사건·기억·시세·후처리 대기로 말한다. `events`, `queued`, `context fallback`은 화면에 없다.
- 종목 축적 맥락의 중요도는 높음·보통·낮음이다. 저장된 값은 바꾸지 않는다.
- 위키 그룹 분포 축은 시장·포트폴리오처럼 보인다. 저장 키는 바꾸지 않는다.

## 화면별 시나리오 추가

- 홈: 장 전에 국면·보유·시장 지도를 먼저 본다. 지도를 누르면 종목 분석으로 간다. S&P500 밸류 설명은 장기 보고이익·선행 PER로 말하고, 출처 도메인은 보이지 않는다.
- 포트폴리오: 한국 보유는 원, 미국 보유는 달러다. 보유가 없으면 파일 이름 없이 없다고 말한다.
- 종목 분석: 차트·알림·관련 종목이 한 화면이다. 외부 차트를 못 불러오면 지표 메뉴의 구형 렌더러를 켜라는 안내만 본다. 적정가 라벨은 선행 EPS·선행 PER이다.
- 관심종목: 빈 목록은 추가 방법을 말한다. 행을 누르면 종목 분석으로 간다.
- 국내 ETF: 순자산은 원 단위다. 구성 출처는 시세 구성처럼 보이고, 행을 누르면 종목 분석으로 간다.
- 리서치: 스크리너에서 종목을 누르면 같은 종목 분석으로 간다. 축 게이트는 관찰·통과·차단이다.
- 차트 워크스페이스: 저장·불러오기가 실패하면 다시 시도하라는 안내만 본다. 경로와 예외 본문은 로그에 남긴다.
- 전략 스튜디오: 벤치마크를 비우면 기준 종목을 쓴다고 말한다. 저장 키 이름은 도움말에 없다.
- AI 콘솔: 제목 위의 작은 글씨는 퀀트 터미널이다. 상태줄은 사건·기억·시세·후처리 대기다.
- 위키 그래프: 제목은 연결된 기억·지식 그물이다. 상태줄은 노드·연결·묶음·화면·상태이고, 필터 키는 보이지 않는다. 화면 맞춤은 그래프를 다시 맞춘다.

## 이번 화면 문구

- 위키 그래프 제목·상태줄·맞춤 버튼이 영어 키를 그대로 보여 주던 문제. 화면 문구만 한국어로 바꾼다.
- 전략 스튜디오 벤치마크 도움말이 `base_symbol`을 보여 주던 문제. 기준 종목이라고 말한다.
- 차트 로드 실패와 구형 렌더러 도움말이 `plotly.js CDN`을 보여 주던 문제. 불러오지 못했다는 안내로 바꾼다.
- AI 콘솔 작은 제목이 `stock-report agent`이던 문제. 퀀트 터미널로 바꾼다.

## 지표 라벨

- 종목 화면의 `Fwd PE`와 도움말의 `Fwd/TTM`, `5y`를 선행 PER과 연 단위로 바꿨다.
- 밸류에이션 칩과 환전 타이밍의 `%ile`, `20y`, `5y`를 백분위와 연 단위로 바꿨다.
- 포트폴리오의 `½Kelly`를 켈리 절반으로, 관심종목 공시 금액의 `bracket`을 신고 구간으로 바꿨다.
- 스크리너 근거 `6M`/`1M`/`60d`를 개월·일로 바꿨다. 백테스트 단일 곡선 범례 `equity`는 순자산이다.
- 홈 국면 라벨, 리서치 백테스트·게이트, 위키 건강 지표, 전략 샤프·회전율도 화면 문구만 한국어로 바꿨다. 저장 키는 그대로다.
- 홈·종목 적정가 라벨이 `multpl.com`·`Forward EPS`·`fPER`이던 문제. 장기 보고이익·선행 EPS·선행 PER로 바꾼다.
- 종목 수급·컨센서스와 홈 지도 설명이 `Naver`·`marcap`·`Plotly`를 보여 주던 문제. 네이버·시가총액·표시 상한으로 바꾼다.
